# Ceryx v0.3 W2 Agent Foundation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the W1 Agent skeleton into a local Windows Agent host with Kestrel, SQLite, logging, tray lifecycle, and Desktop management APIs.

**Architecture:** `Ceryx.Agent.App` owns process startup and tray/settings shell. `Ceryx.Agent.Network` owns HTTP routing. `Ceryx.Agent.Storage` owns SQLite and local paths. `Ceryx.Agent.Core` owns DTOs, options, result/error contracts, and shared constants.

**Tech Stack:** .NET 10 LTS, ASP.NET Core Minimal API, Microsoft.Extensions.Hosting, SQLite, Serilog, WinUI 3 placeholder tray/settings shell.

---

## Success Criteria

- Agent starts and exposes `/api/v1/health`, `/api/v1/agent/status`, `/api/v1/agent/paths`.
- SQLite database initializes under `%LOCALAPPDATA%/Ceryx`.
- Logs are written under `%LOCALAPPDATA%/Ceryx/Logs`.
- Desktop local management endpoints exist but dangerous actions are guarded.
- Tests cover health/status contracts, local path creation, and basic storage initialization.
