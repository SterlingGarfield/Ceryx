# Ceryx v0.3 W6 Diff Logs Settings Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete Diff, Files, Logs, Notifications, Tasks, and Settings workspaces for both iPad and Desktop.

**Architecture:** Agent owns project, Git, logs, settings, and media data. Frontends request paginated or per-file data through SDK. Desktop gets higher-density resizable workspaces; iPad gets touch-first drawers, sheets, and simplified reading layouts.

**Tech Stack:** React, TypeScript, Zustand, virtual lists, CodeMirror/react-diff-view, ASP.NET Core APIs, Git CLI, SQLite logs/settings repositories.

---

## Success Criteria

- Diff files load per file and avoid full unbounded payloads.
- Desktop Diff is a three-column resizable workspace.
- iPad Diff is touch-readable with file list and prompt actions.
- Logs support pagination, filters, copy, and export.
- Settings separates client settings from Agent settings.
- Files, Tasks, and Notifications have complete empty/loading/error states.
