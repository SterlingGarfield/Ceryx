# Ceryx v0.3 W5 Dual Client Control Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire iPad and Desktop shells to the Agent SDK so both clients can connect, pair, view Codex status, send prompts, use primary controls, and handle offline/error states.

**Architecture:** Shared SDK and feature packages own protocol behavior. `apps/ipad` owns touch-first layout and gestures. `apps/desktop` owns desktop navigation, menus, status bar, shortcuts, and resizable panels. Views must not embed raw fetch calls.

**Tech Stack:** React, TypeScript, Vite, Tailwind CSS, Zustand, Capacitor shell, Tauri shell, Vitest, Playwright/browser smoke checks.

---

## Success Criteria

- iPad and Desktop can complete discovery, pairing, connect, disconnect, and reconnect.
- Both clients show Codex window status and capture state.
- Both clients can send Prompt through SDK.
- Desktop supports shortcuts and right-click menus for primary actions.
- iPad supports horizontal live layout, bottom action bar, prompt panel, voice/image entry points.
- All async states have loading, success, and error UI.
