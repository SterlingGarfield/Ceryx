# Ceryx v0.3 W4 Remote Control Transport Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Agent-side Codex window discovery, capture lifecycle, input bridge, prompt send, image send, screenshot, and recording service boundaries behind permissions and session lock.

**Architecture:** Network routes call service interfaces only. `Ceryx.Agent.Codex` owns window location, focus, input, clipboard, and image bridge. `Ceryx.Agent.Capture` owns capture lifecycle and frame transport. `Ceryx.Agent.Media` owns screenshots, recordings, asset storage, and cleanup.

**Tech Stack:** .NET 10, Win32 EnumWindows, Windows.Graphics.Capture, SendInput, Windows Clipboard APIs, WebSocket, WebRTC signaling stub, SQLite audit log.

---

## Success Criteria

- Agent reports Codex window states: `not_found`, `found`, `focused`, `minimized`, `multiple_candidates`, `permission_issue`.
- Capture can start/stop for the bound Codex window without exposing full desktop capture.
- Input commands are accepted only for active session with `control_input`.
- Prompt send uses clipboard paste plus optional submit.
- Image upload saves assets and attempts image paste strategy.
- Screenshot and recording APIs are permission-gated and audited.
