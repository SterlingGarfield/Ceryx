# Ceryx v0.3 W8 Release Acceptance Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a reviewable v0.3 release package with Desktop + Agent installer path, iPad build path, acceptance report, known issues, and operator documentation.

**Architecture:** W8 does not add new product scope. It packages the already verified build, checks installation/runtime behavior, and turns the implementation into a handoff-ready artifact set.

**Tech Stack:** pnpm, Tauri build, Capacitor iOS build path, dotnet publish, Windows installer script, release docs, smoke test scripts.

---

- Desktop app and Windows Agent can be built from a clean checkout.
- Windows release package includes Desktop and Agent.
- iPad build path is documented and repeatable.
- Acceptance checklist maps back to frontend, backend, and technical requirements.
- Known issues and non-goals are explicit.
- Final verification commands pass or documented blockers are precise.
