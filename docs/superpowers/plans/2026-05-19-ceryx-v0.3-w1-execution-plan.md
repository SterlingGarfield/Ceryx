# Ceryx v0.3 W1 Execution Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v0.3 foundation for Ceryx: a clean monorepo, shared frontend packages, protocol contracts, and a minimal Windows Agent skeleton ready for W2 integration.

**Architecture:** W1 does not implement remote control yet. It creates the project boundaries first: `apps/ipad` and `apps/desktop` own platform shells, `packages/*` owns shared UI/protocol/client logic, and `agent/windows` owns the local Windows Agent. Protocol types are defined before UI and backend implementation so later work uses one shared contract.

**Tech Stack:** pnpm workspace, React, TypeScript, Vite, Tailwind CSS, Capacitor, Tauri 2, .NET 10 LTS, ASP.NET Core Minimal API, SQLite-ready project structure.

- [x] Implement SDK URL and token handling:

```ts
export interface AgentClientOptions {
  baseUrl: string;
  getToken?: () => string | undefined;
  fetchImpl?: typeof fetch;
}

export class AgentClient {
  private readonly fetchImpl: typeof fetch;

  constructor(private readonly options: AgentClientOptions) {
    this.fetchImpl = options.fetchImpl ?? fetch;
  }

  async health(): Promise<{ ok: true }> {
    return this.request("/api/v1/health", { auth: false });
  }

  async agentStatus() {
    return this.request("/api/v1/agent/status", { auth: true });
  }

  private async request(path: string, config: { auth: boolean }) {
    const headers: Record<string, string> = {
      "Accept": "application/json"
    };

    const token = this.options.getToken?.();
    if (config.auth && token) {
      headers.Authorization = `Bearer ${token}`;
    }

    const response = await this.fetchImpl(`${this.options.baseUrl}${path}`, {
      headers
    });

    return response.json();
  }
}
```
