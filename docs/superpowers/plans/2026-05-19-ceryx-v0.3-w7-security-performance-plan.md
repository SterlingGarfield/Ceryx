# Ceryx v0.3 W7 Security Performance Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden v0.3 for security, permissions, auditability, performance, failure states, and sustained local-network use.

**Architecture:** Security checks are centralized in Agent middleware/services and mirrored in frontend disabled states. Performance work focuses on transport degradation, virtualization, pagination, capture throttling, and measurable acceptance thresholds.

**Tech Stack:** ASP.NET Core middleware, SQLite audit logs, Windows performance counters/process metrics, Vitest, xUnit, Playwright/browser smoke checks.

---

## Success Criteria

- Every protected API has token, permission, and session validation.
- High-risk actions require confirmation and audit logs.
- Agent rejects public binding by default.
- Capture, logs, diff, and recording have resource guards.
- Performance targets from requirements are measured and documented.
