# Ceryx v0.3 W7 Security Performance Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden v0.3 for security, permissions, auditability, performance, failure states, and sustained local-network use.

**Architecture:** Security checks are centralized in Agent middleware/services and mirrored in frontend disabled states. Performance work focuses on transport degradation, virtualization, pagination, capture throttling, and measurable acceptance thresholds.

**Tech Stack:** ASP.NET Core middleware, SQLite audit logs, Windows performance counters/process metrics, Vitest, xUnit, Playwright/browser smoke checks.

---

## Success Criteria

- Every protected API has token, permission, and session validation.
- High-risk actions require confirmation and audit logs.
- Agent rejects public binding by default.
- Capture, logs, diff, and recording have resource guards.
- Performance targets from requirements are measured and documented.

## Task 1: Permission Coverage Audit

- [ ] Create endpoint-permission matrix in code and documentation.
- [ ] Add tests that enumerate protected routes and verify permission metadata exists.
- [ ] Ensure remote clients cannot call local-only Agent management routes.
- [ ] Ensure deleted trusted devices invalidate tokens and sessions.

Run:

```powershell
dotnet test agent/windows/Ceryx.Agent.Windows.sln --filter PermissionCoverage
```

Expected: no protected route is missing permission metadata.

## Task 2: High-Risk Confirmation

- [ ] Require confirmation token or explicit flag for Stop current task, Start recording, Delete trusted device, Enable direct test command, Clear logs, Change port, Allow full-screen capture.
- [ ] Frontend shows confirmation dialog/sheet before calling guarded endpoint.
- [ ] Audit log includes action, device id, session id, severity, and result.

Run:

```powershell
dotnet test agent/windows/Ceryx.Agent.Windows.sln --filter HighRiskActions
pnpm test -- --run confirmation
```

Expected: guarded actions reject calls without confirmation.

## Task 3: Network and CORS Hardening

- [ ] Default Agent binding allows loopback and LAN only.
- [ ] Reject unknown origins by default.
- [ ] WebSocket handshake validates token.
- [ ] Pairing API has rate limiting.
- [ ] Add trace id to all error responses.

Run:

```powershell
dotnet test agent/windows/Ceryx.Agent.Windows.sln --filter NetworkSecurity
```

Expected: invalid origin, invalid token, and pairing flood cases are rejected.

## Task 4: Performance Degradation

- [ ] Capture drops frame rate when CPU stays above 70% for 5 seconds.
- [ ] Network jitter lowers resolution before disconnecting.
- [ ] Pause capture when no active viewer exists for over 3 seconds.
- [ ] Diff file list and logs remain paginated.
- [ ] Recording refuses start below 1GB free disk.

Run:

```powershell
dotnet test agent/windows/Ceryx.Agent.Windows.sln --filter PerformancePolicy
pnpm test -- --run virtualized
```

Expected: degradation policies are deterministic in tests.

## Task 5: Frontend Error State Completion

- [ ] iPad and Desktop implement Agent offline, not paired, Codex not found, Codex minimized, capture failed, input blocked, diff too large, recording disk low.
- [ ] Controls disable based on permission and active session.
- [ ] Status bar shows connection, latency, frame rate, token verified, recording state.
- [ ] Toasts and dialogs use protocol error hints where available.

Run:
