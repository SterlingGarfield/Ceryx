# Ceryx v0.3 Release Notes

## Scope

Ceryx v0.3 delivers iPad + Desktop control clients backed by a local Windows Agent with:

- Pairing and trusted-device token model.
- Agent-side permission matrix and local-only route restrictions.
- High-risk confirmation gates with audit logs.
- Remote control transport flows (capture/input/prompt/image/diff/logs/settings).
- W7 hardening and performance measurement artifacts.

## Non-goals for v0.3

- Cloud relay / internet relay control.
- Account system and multi-user tenancy.
- Multiplayer shared workspace.
- Plan/Schedule/Channel feature set.
- Default full-screen capture.
