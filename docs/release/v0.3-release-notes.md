# Ceryx v0.3 Release Notes

## Scope

Ceryx v0.3 delivers iPad + Desktop control clients backed by a local Windows Agent with:

- Pairing and trusted-device token model.
- Agent-side permission matrix and local-only route restrictions.
- High-risk confirmation gates with audit logs.
- Remote control transport flows (capture/input/prompt/image/diff/logs/settings).
- Phase 1 real-frame viewport preview on both iPad and desktop:
  - authenticated `GET /api/v1/capture/frame`
  - GDI/PrintWindow Codex-window capture
  - in-memory JPEG preview frames with client polling
  - last-frame freeze + status overlay fallback
- Explicit screenshot path now captures the same real Codex window source and persists PNG artifacts.
- W7 hardening and performance measurement artifacts.

## Viewport Preview Transport

- Preview route:
  - `GET /api/v1/capture/frame`
  - permission: `view_window`
  - payload: `image/jpeg`
  - headers: captured-at / width / height / `Cache-Control: no-store`
- Screenshot route:
  - `POST /api/v1/media/screenshot`
  - permission: `screenshot`
  - payload: saved PNG artifact metadata
- Phase 1 preview is poll-based and memory-backed. It is intentionally **not** WebRTC streaming in v0.3.

## Non-goals for v0.3

- Cloud relay / internet relay control.
- Account system and multi-user tenancy.
- Multiplayer shared workspace.
- Plan/Schedule/Channel feature set.
- Default full-screen capture.
