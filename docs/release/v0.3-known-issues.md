# Ceryx v0.3 Known Issues

## Packaging

1. Desktop Tauri packaging is blocked by missing `apps/desktop/src-tauri/Cargo.toml`.
   - Impact: `scripts/build-all.ps1` fails when Desktop Tauri step is enabled.
   - Workaround: run `scripts/build-all.ps1 -SkipDesktopTauri` for Agent + web bundle verification.

## Smoke Coverage

1. Local desktop smoke script is newly added and not yet fully exercised in this report cycle.
   - File: `scripts/smoke-local-desktop.ps1`
   - Impact: end-to-end local runtime smoke evidence is partial.

## Release Scope Constraints

These are intentional non-goals for v0.3 and should not be treated as defects:

- Cloud relay control.
- Account/tenant system.
- Multiplayer collaborative workspace.
- Plan/Schedule/Channel workflow.
- Default full-screen capture.
