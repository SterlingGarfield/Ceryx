# Ceryx v0.3 Known Issues

## iPad Native Runtime Validation Scope

1. Repository-level iOS permission descriptors are now committed and auditable, but Xcode runtime verification still requires macOS host execution.
   - Impact: native Debug launch and device/simulator runtime evidence cannot be generated from this Windows execution environment.
   - Workaround: run Xcode Debug build on a macOS host and archive output alongside release evidence.

## Local Smoke Preconditions

1. Protected Agent APIs require a valid trusted-device token.
   - Impact: smoke commands against `/api/v1/agent/status` and local management routes fail with 401 when no trusted token exists.
   - Workaround: pair once to obtain a token, or seed a local trusted-device token in a dedicated smoke runtime root before executing smoke scripts.

## Local .NET Tooling Baseline

1. This Windows machine's system-level `dotnet` 10.0.300 installation has a broken workload import/resolver path.
   - Impact: direct `dotnet restore/test` from `C:\Program Files\dotnet` can fail even when the repository code is healthy.
   - Workaround: use the repo-local SDK at `.cache/dotnet-sdk-10.0.300\dotnet.exe` for `agent/windows` restore/test commands until the machine-level SDK is repaired.

## Release Scope Constraints

These are intentional non-goals for v0.3 and should not be treated as defects:

- Cloud relay control.
- Account/tenant system.
- Multiplayer collaborative workspace.
- Plan/Schedule/Channel workflow.
- Default full-screen capture.
- True WebRTC/streaming viewport transport. Current viewport preview is a polled latest-frame JPEG implementation.
