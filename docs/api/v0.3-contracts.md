# Ceryx v0.3 Contracts

This document records the initial shared protocol contract for Ceryx v0.3. The TypeScript source of truth lives in `packages/protocol/src`.

## Public Routes

Only these routes are public before pairing:

- `GET /api/v1/health`
- `POST /api/v1/pairing/request`

All control, settings, media, project, and device APIs require authentication. Permission-specific APIs also require the matching permission.

## Error Envelope

```json
{
  "ok": false,
  "error": {
    "code": "E_CODEX_NOT_FOUND",
    "message": "Codex window was not found.",
    "hint": "Open Codex Desktop app and retry.",
    "traceId": "trace_001"
  }
}
```

Required error codes:

- `E_AGENT_OFFLINE`
- `E_NOT_PAIRED`
- `E_TOKEN_INVALID`
- `E_PERMISSION_DENIED`
- `E_CODEX_NOT_FOUND`
- `E_CODEX_MINIMIZED`
- `E_CAPTURE_DENIED`
- `E_CAPTURE_FAILED`
- `E_INPUT_BLOCKED`
- `E_UPLOAD_TOO_LARGE`
- `E_DIFF_TOO_LARGE`
- `E_RECORDING_BUSY`
- `E_DISK_LOW`
- `E_AGENT_PAUSED`

## Agent Status

```json
{
  "agentVersion": "0.3.0",
  "deviceName": "Akina-PC",
  "platform": "windows",
  "status": "running",
  "httpPort": 41527,
  "supportsWebRTC": true,
  "supportsDesktopClient": true,
  "codexStatus": "detected"
}
```

The protocol type uses the normalized `codexStatus` values:

- `not_found`
- `found`
- `focused`
- `minimized`
- `closed`
- `multiple_candidates`
- `permission_issue`

## Event Envelope

```json
{
  "eventId": "evt_001",
  "type": "codex.window.found",
  "sessionId": "sess_001",
  "timestamp": "2026-05-19T10:00:00+09:00",
  "payload": {}
}
```

Initial event types include connection, agent, Codex window, capture, input, prompt, diff, media, notification, audit, and error events.
